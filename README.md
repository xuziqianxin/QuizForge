# QuizForge

基于 Python + [Textual](https://github.com/Textualize/textual) 的终端题库工具:

- 📚 **题库管理** — 按学科分类、增删改查、关键词/题型检索、JSON/HTML 导出
- ✏️ **答题练习** — 分类抽题/文件选题、答题卡(查看已答并跳题)、提交后回看作答与正确答案;每分类的「XX错题」子分类可直接重练本学科错题
- ⏱️ **限时模拟考试** — 倒计时显示、时间到自动交卷;答题全程自动计时(可暂停/继续)
- 🔀 **随机化** — 无放回随机抽题、可选题目/选项乱序(默认关闭,可在「开始答题 → 答题设置」中开启)
- 📊 **历史成绩** — 每次提交自动记录得分/用时/题型分布,可查看逐题作答详情并导出 HTML 试卷
- 🌐 **学习通拉取** — 登录超星学习通,按课程自动分类导入作业题目
- 🛡️ **数据保护** — 所有数据写入前自动备份到 `data/backup/`,设置内可一键恢复
- 🧱 **可扩展** — 模型 / 存储 / 服务 / 界面分层解耦,新增题型或数据源只需扩展对应模块

> 📋 更新记录见 [CHANGELOG.md](CHANGELOG.md)。
> 📖 详细操作步骤见下文 [操作指南](#操作指南)。
> 开发约定(每次改代码):先 `python tools/backup_code.py` 备份源码 → 修改 →
> 同步更新 README.md 与 CHANGELOG.md。

## 环境要求

- Python 3.10+(开发环境为 3.12)
- 依赖: `textual`、`requests`、`beautifulsoup4`、`qrcode`、`pycryptodome`(见 `requirements.txt`)

```bash
pip install -r requirements.txt
```

> 说明:`pycryptodome` 仅用于学习通"账号密码登录"(AES 加密),使用二维码登录
> 或纯题库功能时不需要。

## 运行

**Windows(推荐,双击或命令行均可):**

```bat
start.bat        :: 批处理启动脚本
start.ps1        :: PowerShell 启动脚本(推荐)
```

**Unix / macOS:**

```bash
./start.sh
```

启动脚本会自动探测可用的 Python 解释器(优先选择已安装 `textual` 的版本,
依次尝试 py 启动器 → PATH 中的 python → `PYTHON_HOME` 指向的解释器),
首次运行会自动安装依赖,无需手动配置。

**Windows 免安装版(exe)**:运行 `python tools/build_exe.py` 可打包出
单文件 `dist/QuizForge.exe`(约 39 MB,含 Python 与全部依赖,目标机器
无需安装 Python)。双击或在终端运行即可;`QuizForge.exe --selftest`
可做无头自检(题库读写/评分/UI 渲染)。

也可以直接运行:

```bash
python main.py
```

请在支持 Unicode 与颜色的终端中运行(推荐 Windows Terminal、Windows 11 终端)。

> 提示:程序第一次运行会在项目根目录创建 `data/` 目录,其中 `data/bank/`
> 为分类题库存储(含 `index.json` 索引与各分类 `<id>.json` 题库文件,
> 错题索引在各自题库文件内部)、`data/config.json` 为设置、
> `data/chaoxing_cookies.json` 为学习通登录状态、`data/templates.json`
> 为抽题配置模板、`data/backup/` 为数据自动备份。

## 操作指南

本章按真实使用流程,逐步说明软件的各项操作。程序为键盘/鼠标均可
操作的终端界面:鼠标点击按钮与控件,键盘负责输入与导航(Tab 切换
焦点、方向键移动、Enter 确认、Escape 返回/退出当前层)。

### 1. 启动与主菜单

启动后进入主菜单,包含 6 个入口:

| 按钮 | 功能 |
|------|------|
| 📚 题库管理 | 分类管理与题目增删改查 |
| ✏️ 开始答题 | 分类抽题 / 文件选题(含「XX错题」子分类重练) |
| 🔍 查题 | 按关键词/题型检索并查看题目 |
| ⚙️ 设置 | 学习通登录管理、开关状态查看、数据概况 |
| 🌐 从学习通导入 | 登录超星学习通并拉取作业题目 |
| 🚪 退出 | 退出程序(Ctrl+Q 快捷键等效) |

### 2. 题库管理

在主菜单点「题库管理」进入。界面分四部分:**分类栏**(顶部)、
**检索栏**(分类栏下方)、**题目表格**(中部)、**操作按钮**(底部)。

#### 2.1 分类操作

- **新建分类**:点「新建分类」,输入分类名称(如"高等数学")并确定。
  新建后自动切换到新分类,后续添加的题目都会进入该分类。
- **切换分类**:点分类下拉框选择目标分类,表格随即显示该分类题目。
- **删除分类**:选中要删除的分类(非默认分类)后点「删除分类」,二次
  确认后删除(连同其中题目,删除前自动备份)。**默认分类不可删除**,
  选中它时删除按钮自动禁用;「XX错题」子分类是聚合视图,同样不可
  删除(删除按钮自动禁用)。

> 分类按学科/课程划分,每个分类独立存储为一个 JSON 文件,互不影响;
> 学习通导入时会自动创建与课程同名的分类。

#### 2.2 添加题目

点「添加」进入编辑表单,按题型填写:

| 字段 | 说明 |
|------|------|
| 题型 | 单选 / 多选 / 判断 / 填空 / 简答 |
| 题干 | 题目文本 |
| 选项 | 选择题:每行一个选项,自动编号 A/B/C...;判断题无需填写 |
| 答案 | 单选:A;多选:A,C;判断:对/错;填空/简答:答案文本(多个可接受答案用 `|` 分隔) |
| 解析 | 可选,讲解文字 |
| 来源 | 可选,如"超星学习通 - 作业名" |

填写完成后点「保存」;「取消」返回(有未保存修改时先确认)。

#### 2.3 编辑 / 删除题目

- **编辑**:在表格中单击(高亮)目标行,点「编辑」修改后保存。
- **删除**:高亮目标行,点「删除」,二次确认后删除。

> 表格列依次为:序号 / 类型 / 题干 / 答案 / 来源。未设置标准答案的题
> (如学习通导入)答案列以 **黄色 ⚠ 未设答案** 醒目标记。

#### 2.4 检索

检索栏输入框按关键词**实时过滤**当前分类(匹配题干/选项/答案/解析/
来源),可叠加右侧题型下拉过滤。清空关键词恢复全部。

表格**分页浏览**:每页最多 50 题,底部「◀ 上一页 / 下一页 ▶」翻页并
显示「第 X / Y 页」,大题库可翻页看全量(不再截断为 500 条)。翻页后
行号按本页重新编号。

#### 2.5 错题管理

分类下拉框中,每个真实分类后紧跟其**「XX错题」**虚拟分类(如「虚拟化
错题」),聚合该分类的错题索引,选中后表格显示本学科错题。点「错题」
打开错题管理弹窗:列出当前分类错题(题干摘要),可「移除选中」逐题
移出,或「全部移除」清空。错题由回看界面「加入错题本」写入,用于
「错题重练」。

> 「XX错题」是聚合视图,题目归属真实分类:在此不能添加/编辑/删除
> 题目(按钮自动禁用),请切换到题目所属的真实分类操作。

#### 2.6 导入 / 导出

- **导出(JSON)**:选择分类后点「导出」,输入输出文件路径(默认
  `data/export_日期.json`),导出该分类当前检索结果的 JSON。
- **导出 HTML 试卷**:点「导出HTML」,把当前分类检索结果导出为
  **HTML 试卷**(题干 + 选项带字母 + 作答区:选择题可勾选、填空/简答
  可填写),浏览器打开后可查看,**可打印成纸质练习**(TODO 08)。
- **导入**:选择目标分类后点「导入」,输入文件路径。支持两种格式:
  `{"questions": [...]}` 或直接是题目列表;按「题型 + 题干」自动去重,
  重复题跳过。导入完成后弹出**详细报告**:新增/跳过数量,并**列出
  跳过的题目**(最多 50 条),便于发现"作业更新了但题库没变"。
  学习通导入同样展示该报告。

### 3. 查题

主菜单点「查题」进入。检索栏支持关键词 + 分类 + 题型过滤;结果表格
**分页浏览**(每页 50 题,底部翻页),单击行即在下方面板显示详情
(题型/来源/题干/选项/答案/解析),点「编辑此题」可直接修改。

### 4. 答题练习

主菜单点「开始答题」进入答题设置界面,提供**两种选题方式**
(顶部下拉切换);分类抽题的分类下拉中每个真实分类后紧跟其
**「XX错题」**子分类,错题与普通分类使用同一套抽题/答题流程。

#### 4.1 方式一:分类抽题

1. 选择「分类抽题」,在下拉框选择题目来源分类;
2. 点「抽题设置」配置各题型抽取数量:
   - 每种题型一个数字输入框,旁边实时显示该分类最大可用数;
   - 输入超过上限时**自动修正为最大值**;
   - 可点「保存为模板」把配置存为模板(如"单元小测"),之后用
     「选择模板」一键套用,「删除模板」移除;
3. 确认后回到设置界面,预览区显示**具体抽中的题目**;
4. 点「开始答题」进入答题。

> **配置自动保留**:确认过的配置会自动记忆,不退出答题系统时点
> 「再练一次」自动复用上次配置并重新抽题,无需重复设置。

**答题开关**(答题设置界面下方的三个勾选框 + 限时输入,**即改即存到全局设置**):
- **随机打乱题目顺序**:答题时题目次序随机(默认关);
- **随机打乱选择题选项顺序**:选项次序随机(默认关);
- **分类抽题时排除无答案题目**:开启后抽题只抽有标准答案的题,
  抽题设置中的各题型上限同步按过滤后数量显示(默认关);切换后
  已配置的抽题会立即按新规则重新抽取;
- **限时模拟考试(分钟)**:输入分钟数开启**倒计时模式**(0 或留空 =
  不限时)。限时模式下答题界面显示「剩余 MM:SS」,**时间到自动交卷**
  (无需手动提交,未答题按未答计分)。

> 以上配置与「设置」界面显示的是同一份全局配置:在答题设置里
> 修改即保存,设置界面只做查看,两处状态始终一致。

#### 4.2 方式二:文件选题

1. 选择「文件选题」,在输入框填入题目文件路径;
2. 点「读取」,预览区显示匹配到的题目;
3. 点「开始答题」。

文件格式(JSON 或纯文本):
- `{"ids": ["题目id", ...]}` — 按题目 id 跨分类匹配;
- `{"texts": ["题干", ...]}` — 按题干精确匹配;
- `{"questions": [题目字典, ...]}` — 直接提供题目(无需提前入库);
- 纯文本:每行一个题干。

#### 4.3 答题界面

- **作答**:单选/判断题点选一个选项,多选题勾选多个,填空题输入文本,
  简答题在文本框作答;
- **上一题 / 下一题**:切换题目(自动保存当前作答);
- **答题卡**:查看全部题目作答状态(已答显示所选答案),点击行号跳转
  到对应题;
- **暂停 / 继续**:暂停计时(**每秒实时刷新**显示,暂停期间用时不再
  累加,且**作答/切题/提交全部冻结**,只能点「继续」恢复),再点
  一次继续;
- **计时显示**:不限时为正计时「用时 MM:SS」;开启**限时模拟考试**后
  为倒计时「剩余 MM:SS」,**时间到自动交卷**;
- **提交**:完成作答后点「提交」;还有未答题时二次确认。提交后进入
  **回看**界面。

> 每次答题**自动计时**,进入答题即开始;暂停、退出答题、提交(或
> 限时到点自动交卷)都会停止计时,提交后本次用时显示在回看摘要中。

#### 4.4 回看界面

- 顶部摘要:得分(自动评分题)、正确/错误/未答数、**用时**、未设答案
  题数;
- 左侧题目列表:✓ 正确 / ✗ 错误 / ○ 未答,点击跳转;
- 右侧详情:题目、你的作答、正确答案与解析;
- 简答题不自动评分(标注人工核对);无标准答案题显示
  "正确答案: (未设置,可在题库管理中补充)"。

下方按钮:
- **加入错题本**:把本次**答错**的题目按所属分类加入错题记录(跨
  分类题目各自归位;重复加入自动去重,不重复计数)。从「XX错题」
  子分类开始的错题重练不显示此按钮(答对自动移出、答错保留);
- **再练一次**:回到答题设置,自动复用上次抽题配置;
- **返回主菜单**:回到主菜单。

#### 4.5 错题重练(通过「XX错题」分类)

答题设置的分类下拉中,**每个真实分类后面紧跟它的「XX错题」分类**
(如「虚拟化」之后是「虚拟化错题」、「网络」之后是「网络错题」),
选中后走**与普通分类完全相同的分类抽题流程**:

- 点「抽题设置」按题型配置抽取数量(可保存/加载/删除模板),**错题
  太多时可以只抽一部分**,不用每次全做;
- 每个错题分类只聚合**本学科**的错题(错题索引存于对应分类文件内部
  `wrong_ids` 字段),不同学科错题互不混淆;
- 进入答题后**答对的题目自动移出该分类的错题索引**(练会了就不再
  重复练),答错的保留,继续重练;
- 错题记录由回看界面「加入错题本」写入,也可在**题库管理 -> 错题**
  中查看并手动移除(逐题移除或全部清空);
- 删除题目时自动从错题索引清理;
- 「XX错题」分类中「开始答题」无需任何额外配置,与普通分类体验一致。

### 5. 设置

主菜单点「设置」进入,包含:

- **学习通登录状态**:查看/清除登录态;
- **答题选项**:显示当前全局设置的状态(随机题目顺序/随机选项顺序/
  排除无答案题目/限时模拟考试)——**修改请到「开始答题 -> 答题设置」
  界面**,那里的开关即改即存,设置界面与答题界面看到的是同一份设置,
  不会出现两处状态不一致;
- **数据概况**:分类数/题目总数/模板数/各文件路径;
- **历史成绩**:点「历史成绩」查看每次答题记录(时间/来源/得分/正确率/
  用时/题型分布,按时间倒序),选中后可**查看逐题作答详情**、**导出为
  HTML 试卷**(浏览器查看/打印),或删除单条/清空全部;
- **备份恢复**:点「备份恢复」列出 `data/backup/` 全部备份(显示原文件
  名、备份时间与大小),选中一份后二次确认还原到其目标位置;恢复前
  自动备份当前文件,误恢复可再还原。

直接「返回」即可,无需保存。

### 6. 从超星学习通导入

1. 主菜单点「从学习通导入」;
2. **登录**(二选一):
   - **账号密码登录**:输入手机号/学号与密码(密码仅用于本次请求,
     不保存;登录态以 Cookie 持久化,下次免登录);
   - **二维码登录**:终端显示二维码,用学习通 App「扫一扫」登录;
3. 依次选择**课程** → **作业**,自动拉取并解析题目,预览题量与题型
   (已提交作业连同正确答案一起拉取);
4. 点「导入选中作业」:自动创建/复用与课程同名的分类,题目导入该分类
   (按「题型 + 题干」去重),各课程互不混淆。

> **无答案题目**:未提交/未批阅的作业没有正确答案,导入后题目答案为空。
> 这类题全程有兜底——题库/查题显示「未设答案」,照常可抽可答,但
> **不计入自动评分**;可在题库管理中为它们补充答案后再参与评分,
> 或在答题设置的「分类抽题时排除无答案题目」开关中跳过这类题。

> 学习通接口可能随平台改版而变化(接口地址集中在 `quizforge/chaoxing/
> endpoints.py`,解析集中在 `parser.py`);有反爬机制,请勿高频请求,
> 且仅用于拉取本人账号的作业题目。命令行预登录可选:
> `python tools/chaoxing_login.py 手机号`。

**题型识别规则**(多选题不再误判为单选):
- **题干提示词优先**:题干含"多选题/(多选)/[多选]"等字样直接判定多选,
  即使答案区缺失也不会被当成填空/简答;单选/判断/填空/简答同理;
- 选项为 checkbox 控件的表单页直接判定多选;
- 正确答案无分隔符(如 `AC`)时逐字母拆分为 `A、C`;答案带解析等
  杂质文本时回退提取其中字母;
- input 的 value 为数字等非法键时自动回退为 A/B/C 字母键。

## 功能特性

- **按学科/课程分类**:独立 JSON 文件存储,互不影响,加载快、内存可控;
- **五种题型**:单选、多选、判断、填空、简答,选择题选项自动编号;
- **默认分类保护**:内置「默认分类」不可删除;
- **显示上限**:表格/检索**分页浏览**(每页 50 题,可翻页看全量);
- **无答案题醒目标记**:答案列黄色 ⚠ 提示;
- **文件感知**:题库文件被外部修改/删除时自动重新加载;
- **答题计时**:每次答题自动计时(每秒实时刷新),支持暂停/继续
  (暂停期间作答冻结),回看显示用时;**限时模拟考试**支持倒计时
  显示与到点自动交卷;
- **错题(每分类子分类)**:每个分类文件内部维护错题索引;分类下拉中
  每个真实分类后紧跟「XX错题」子分类(如「虚拟化错题」),只聚合本
  学科错题,走与普通分类相同的抽题流程(可只抽部分),答对自动移出;
  题库管理可查看/手动移除;
- **索引统计**:`index.json` 记录各分类题目数与总题数;
- **历史成绩**:每次提交自动记录得分/正确率/用时/题型分布
  (`data/history.json`,按时间倒序),设置内可**查看逐题作答详情**、
  **导出 HTML 试卷**、删除单条或清空;
- **HTML 试卷导出**:题库管理导出 HTML 试卷(题干/选项/答题区,可打印
  纸质练习),历史作答记录同样可导出为 HTML;
- **导入报告细化**:导入后弹窗显示新增/跳过数并列出跳过的题目,
  便于发现作业更新但题库未变;
- **备份恢复界面**:设置内列出 `data/backup/` 备份并一键还原(恢复前
  自动备份当前文件,恢复索引自动刷新统计);
- **免安装打包**:`tools/build_exe.py` 一键打包单文件 exe(含 Python 与
  依赖,免装环境,支持 `--selftest` 无头自检);
- **界面自适应**:常规终端按钮全部可见,小窗口内容可滚动到达;
- **数据安全**:所有数据写入前自动备份,删除分类同样先备份。

## 数据格式(全部 JSON)

程序的所有持久化数据均为 JSON 格式,统一存放在 `data/` 目录下。
以下逐一说明每种文件的格式。

### 1. 分类索引 `data/bank/index.json`

记录全部分类及其文件映射(新增/重命名/删除分类时更新),并附带
**题目统计信息**(各分类 `count` 与顶层 `total`,题目增删时同步刷新):

```json
{
  "version": 1,
  "total": 128,
  "categories": [
    {"id": "ae498b529449", "name": "高等数学", "file": "ae498b529449.json",
     "count": 80},
    {"id": "default", "name": "默认分类", "file": "default.json",
     "count": 48}
  ]
}
```

字段说明:
- `version`: 存储结构版本号(当前为 1);
- `total`: 全部分类的题目总数(仅统计真实分类题库文件;「XX错题」子分类是聚合视图,题目来自真实分类,不重复计入)。
- `categories[]`: 分类列表,每项含
  - `id`: 分类唯一标识(新建时随机生成 12 位十六进制;内置默认分类固定为 `default`);
  - `name`: 分类显示名(学习通导入时与课程名一致);
  - `file`: 该分类对应的题库文件名;
  - `count`: 该分类的题目数(写入索引时实读各分类文件,保证与题库一致)。

### 2. 分类题库文件 `data/bank/<id>.json`

每个分类一个独立文件,保存该分类的全部题目与**错题索引**:

```json
{
  "version": 1,
  "questions": [
    {
      "id": "a1b2c3d4e5f6",
      "qtype": "single",
      "text": "题干",
      "options": [{"key": "A", "text": "选项文本"}],
      "answer": ["A"],
      "analysis": "解析",
      "source": "超星学习通 - 作业名",
      "created_at": "2025-01-01T00:00:00",
      "updated_at": "2025-01-01T00:00:00"
    }
  ],
  "wrong_ids": ["题目id1", "题目id2"]
}
```

字段说明:
- `id`: 题目唯一标识(uuid4 十六进制);
- `qtype`: 题型,取值 `single`(单选)、`multiple`(多选)、`judge`(判断)、
  `fill`(填空)、`short`(简答);
- `text`: 题干;
- `options`: 选项列表,仅选择题/判断题使用;填空/简答为空数组 `[]`;
- `answer`: 答案。单选/判断为单键 `["A"]`,多选为多键 `["A","C"]`,
  填空/简答为文本列表 `["答案1", "答案2"]`;未设置标准答案为 `[]`
  (如学习通未批阅作业,此类题不参与自动评分);
- `analysis` / `source`: 解析与来源(可选,可为空字符串);
- `created_at` / `updated_at`: 创建/更新时间(ISO 格式);
- `wrong_ids`: 该分类的**错题索引**(只存答错题目的 id,按加入顺序,
  去重)。加载错题按此索引从本文件读取题目;分类下拉中的「XX错题」
  子分类即聚合本分类的 wrong_ids。

### 3. 应用配置 `data/config.json`

保存用户设置(首次运行时自动创建):

```json
{
  "shuffle_questions": false,
  "shuffle_options": false,
  "exclude_no_answer": false,
  "time_limit_minutes": 0,
  "chaoxing_cookie_file": "chaoxing_cookies.json"
}
```

字段说明:
- `shuffle_questions`: 答题时是否随机打乱题目顺序(默认 `false`);
- `shuffle_options`: 答题时是否随机打乱选择题选项顺序(默认 `false`);
- `exclude_no_answer`: **分类抽题时是否排除无标准答案的题目**(默认
  `false`;开启后抽题与抽题设置中的题型上限均按"仅有答案的题"计算,
  可避免抽到学习通导入的无答案题);
- `time_limit_minutes`: **限时模拟考试时长(分钟)**;`0` 表示不限时。
  开启后答题界面倒计时显示「剩余 MM:SS」,时间到自动交卷;
- `chaoxing_cookie_file`: 学习通登录 Cookie 持久化文件名。

### 4. 抽题配置模板 `data/templates.json`

「分类抽题」中保存/加载的题型数量模板:

```json
{
  "version": 1,
  "templates": {
    "单元小测": {"single": 10, "multiple": 5, "judge": 0, "fill": 0, "short": 0},
    "期末考试": {"single": 15, "multiple": 8, "judge": 5, "fill": 3, "short": 2}
  }
}
```

字段说明:
- `templates`: 模板名 -> 各题型抽取数量 的映射(键为题型值,同 `qtype`;
  数量 0 表示该题型不抽)。

### 5. 历史成绩 `data/history.json`

每次提交答题后自动追加一条记录(最多保留 200 条,超出丢弃最旧):

```json
{
  "version": 1,
  "records": [
    {
      "timestamp": "2026-08-15T12:00:00",
      "mode": "exam",
      "category": "高等数学",
      "auto_score": 8,
      "auto_total": 10,
      "correct": 8,
      "wrong": 2,
      "unanswered": 0,
      "no_answer": 0,
      "elapsed_seconds": 745,
      "question_count": 10,
      "type_distribution": {"single": 6, "judge": 4},
      "details": [
        {"qtype": "single", "qtype_label": "单选题", "text": "题干",
         "options": [{"key": "A", "text": "选项"}],
         "user_answer": "A. 选项", "correct_answer": "A. 选项",
         "is_correct": true, "analysis": "解析", "answer": ["A"]}
      ]
    }
  ]
}
```

字段说明:
- `timestamp`: 提交时间(ISO 格式,界面按此倒序排列);
- `mode`: 答题模式 `exam`(普通)/ `wrongbook`(错题重练);
- `category`: 来源分类名(文件选题为「文件选题」,错题重练为「错题重练」);
- `auto_score` / `auto_total`: 自动评分得分与可评分题数;
- `correct` / `wrong` / `unanswered` / `no_answer`: 正确/错误/未答/未设答案题数;
- `elapsed_seconds`: 本次用时(秒);
- `question_count`: 本次题目总数;
- `type_distribution`: 题型 -> 数量 分布(键为题型值);
- `details[]`: 逐题作答详情(供「查看作答」与 HTML 导出):
  - `qtype` / `qtype_label`: 题型值与中文名;
  - `text`: 题干;`options`: 选项列表;
  - `user_answer` / `correct_answer`: 你的作答 / 正确答案(文本);
  - `is_correct`: `true` 正确 / `false` 错误 / `null` 未答或待人工评分;
  - `analysis`: 解析;`answer`: 标准答案键。

「设置 -> 历史成绩」界面可查看逐题详情、导出 HTML 试卷(含判分标注),
并可删除单条/清空全部。

### 6. 学习通登录态 `data/chaoxing_cookies.json`

学习通登录成功后保存的 Cookie 字典(下次启动免登录):

```json
{
  "_uid": "123456789",
  "UID": "abcdef",
  "DedeUserID": "123456789"
}
```

> 字段为学习通下发的 Cookie 键值对(具体键随平台而定)。此文件包含
> 个人登录凭证,请勿分享;「设置 -> 学习通」或
> `python tools/chaoxing_login.py --logout` 可清除。

### 7. 题库导入 / 导出 JSON

题库管理中的「导出」与「导入」使用同一套题目格式。导出文件为:

```json
{
  "version": 1,
  "questions": [
    {"id": "...", "qtype": "single", "text": "...", "options": [...],
     "answer": ["A"], "analysis": "", "source": "", "created_at": "...",
     "updated_at": "..."}
  ]
}
```

导入兼容两种顶层结构(题目字段与分类题库文件一致,`id` 缺失时自动生成):
- `{"questions": [题目字典, ...]}`(带版本包装);
- `[题目字典, ...]`(直接是题目列表)。

导入按「题型 + 题干」去重,重复题目跳过;解析、来源等字段可省略。

### 8. 文件选题 JSON(答题方式二)

通过文件指定要作答的题目,支持三种结构(文件路径在答题设置的
「文件选题」中指定):

```json
{"ids": ["题目id1", "题目id2"]}
```

按题目 id 跨分类匹配。

```json
{"texts": ["题干1", "题干2"]}
```

按题干精确匹配(匹配到多道同题干题时全部纳入)。

```json
{"questions": [题目字典, ...]}
```

直接提供题目(格式同第 7 节,无需提前入库)。

纯文本文件(每行一个题干)同样支持。读取后预览匹配到的题目,可直接开始答题。

### 9. 备份文件 `data/backup/*.bak`

上述各数据文件(分类题库、分类索引、抽题模板、应用配置、历史成绩)在
每次写入前都会自动备份到 `data/backup/`,命名格式为
`<原文件名>.<时间戳>.bak`(毫秒级时间戳),每个文件保留最近 5 份。
备份文件本身也是 JSON,可直接复制回原位置恢复。错题索引在分类题库
文件内部(wrong_ids 字段),随分类文件一并备份。

> 旧版本(1.0 之前的单文件 `data/questions.json`)首次启动时会被自动
> 迁移到默认分类,旧文件改名为 `questions.json.bak`。

## 备份与数据安全

**用户数据自动备份**:所有数据文件(分类题库、分类索引、抽题模板、应用
配置、历史成绩)在每次写入前自动备份到 `data/backup/`,每个文件保留
最近 5 份(毫秒级时间戳命名,同一秒内的多次写入各自独立备份、互不覆盖)。
**删除分类(连同其中题目)同样会在删除前自动备份**,误删后可恢复。

**界面恢复(推荐)**:「设置 -> 备份恢复」打开恢复弹窗,列出 `data/backup/`
全部备份(显示原文件名、备份时间与大小),选中一份后二次确认还原到其
目标位置;**恢复前自动备份当前文件**,误恢复可再还原。恢复分类索引
(`index.json`)时会按恢复后的题库文件自动刷新题目统计。

**命令行恢复**:也可手动将 `data/backup/` 中对应文件的最新 `.bak`
复制回原位置。例如误删了分类 `abc123`:

```bash
# 查看备份
ls data/backup/abc123.json.*.bak
# 恢复(复制最新一份回分类目录)
cp "$(ls -t data/backup/abc123.json.*.bak | head -1)" data/bank/abc123.json
```

恢复后在「题库管理」新建同名分类并确认题目;索引中的分类记录可通过
再次删除该分类文件后由备份恢复,或手动编辑 `data/bank/index.json`。

**开发侧代码备份**:每次修改代码前运行

```bash
python tools/backup_code.py            # 备份全部源码到 _dev_backup/<时间戳>/
python tools/backup_code.py --note "修复答题卡"   # 带说明
```

保留最近 10 份源码备份。开发约定:修改 → 备份 → 更新 README 与 CHANGELOG。
